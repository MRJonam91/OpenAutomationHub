# Sicurezza / Security

**IT:** Questa è un'alfa con validazione statica dei workflow, senza audit indipendente. Non importare o attivare un workflow senza verificarne nodi, destinatari, credenziali e permessi. Segnala vulnerabilità tramite **Report a vulnerability** nella scheda Security del repository o contatta privatamente il maintainer tramite GitHub. Non pubblicare exploit, credenziali o dati personali nelle issue. Il maintainer cercherà di coordinare la divulgazione entro 90 giorni, salvo diverso accordo.

**EN:** This alpha provides static workflow validation and has no independent audit. Review nodes, recipients, credentials and permissions before importing or activating a workflow. Report vulnerabilities through **Report a vulnerability** on the repository Security tab or contact the maintainer privately through GitHub. Do not post exploits, credentials or personal data in issues. The maintainer aims to coordinate disclosure within 90 days unless another timeline is agreed.
