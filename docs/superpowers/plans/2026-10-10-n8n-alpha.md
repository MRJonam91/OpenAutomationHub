# n8n Alpha Implementation Plan

> **For agentic workers:** implement the tasks in order, with a failing behavior test before each production feature.

**Goal:** Deliver a usable static n8n workflow catalog with guided JSON installation and local static validation.

**Architecture:** React/Vite renders checked-in workflow manifests and JSON. A shared JavaScript validation module serves both browser upload and Node CLI. The repository remains the source of truth.

**Tech Stack:** React, Vite, TypeScript UI, JavaScript ESM validator, Vitest, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-10-n8n-alpha-design.md`

## Global Constraints

- UI copy in Italian.
- No backend, account, credential storage, or direct n8n API call.
- Workflow exports are inactive and contain no bound credential IDs/names.
- Validation describes static findings and does not claim runtime safety.
- The main action downloads a JSON and displays import steps.

## Review Focus

- A connection pointing to a missing node must be an error.
- A malformed or non-workflow JSON must be rejected without crashing the UI.
- A workflow containing a bound credential name or obvious inline token must fail catalog validation.
- An unknown node package must produce a warning, not a false compatibility guarantee.
- A requested n8n version below the declared minimum must produce a compatibility finding.

## Tasks

### Task 1: Shared validator and catalog contract

**Files:** `src/lib/validate-workflow.js`, `src/lib/validate-workflow.test.js`, `schemas/workflow-manifest.schema.json`, `scripts/validate-catalog.mjs`.

**Interface:** `validateWorkflow(workflow, options)` returns `{ findings, summary }`; `validateManifest(manifest, workflow)` returns findings. A finding has `severity`, `code`, `message`, and optional `nodeName`.

- [ ] Add tests for malformed input, duplicate/missing node names, broken connections, credential bindings, risky/unknown nodes, and version comparison; run to observe failure.
- [ ] Implement the narrow validator and version comparator; run the tests to green.
- [ ] Make the Node script scan `workflows/n8n/*`, validate all pairs, and exit nonzero on errors; add a small fixture test for a failing catalog entry.

### Task 2: Two real catalog entries and generated documentation

**Files:** `workflows/n8n/*/{manifest.json,workflow.json,README.md}`, `scripts/generate-docs.mjs`, `src/lib/catalog.js`.

**Interface:** `catalog` is an array of `{ manifest, workflow }` sorted by name. README generation uses the manifest and node names.

- [ ] Add catalog loading/validation test for two entries and a stable generated README heading; observe failure.
- [ ] Add importable inactive JSON and manifests with unbound credentials; implement README generator.
- [ ] Run catalog validation and doc generation; inspect generated instructions and JSON.

### Task 3: Catalog and install flow

**Files:** `index.html`, `package.json`, `src/App.tsx`, `src/components/*`, `src/styles.css`, `src/main.tsx`.

**Interface:** selecting a result updates the detail panel; download serializes the selected workflow to `application/json`; install help lists import and credential steps.

- [ ] Add component behavior tests for searching, category filtering, selecting a row and starting installation; observe failure.
- [ ] Implement the Swiss grid screen from `docs/design/catalog-concept.png`, with accessible controls and responsive layout.
- [ ] Run component tests and exercise the flow in a browser.

### Task 4: Browser validator and final verification

**Files:** `src/components/ValidatorView.tsx`, `src/components/ValidatorView.test.tsx`, `README.md`, `docs/workflow-contract.md`.

- [ ] Add tests for valid upload, malformed JSON and file-size rejection; observe failure.
- [ ] Implement local file reading and report display using the shared validator.
- [ ] Run `npm test`, `npm run validate:catalog`, `npm run build`; check the browser at desktop and mobile sizes and compare to the concept.
- [ ] Update repository documentation, commit the branch, and publish it for review.
