# Contribuire / Contributing

**IT:** Ogni nuovo workflow deve includere `workflow.json` disattivato, `manifest.json` conforme a [schema](schemas/workflow-manifest.schema.json) e README con prerequisiti, credenziali, installazione, rischi e rollback. Usa solo dati dimostrativi. Non inviare token, password, webhook privati o identificativi personali. Esegui `npm test`, `npm run validate:catalog` e `npm run build` prima della pull request. I contributi al codice richiedono l'accettazione del [CLA](CLA.md).

**EN:** Each new workflow needs an inactive `workflow.json`, a `manifest.json` matching the [schema](schemas/workflow-manifest.schema.json), and a README covering prerequisites, credentials, installation, risks and rollback. Use only sample data. Do not submit tokens, passwords, private webhooks or personal identifiers. Run `npm test`, `npm run validate:catalog` and `npm run build` before a pull request. Code contributions require acceptance of the [CLA](CLA.md).
